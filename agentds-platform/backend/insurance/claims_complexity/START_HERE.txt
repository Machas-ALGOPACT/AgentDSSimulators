KEY INFORMATION
===============

REQUIRED (User Must Enter):
  - ClaimID, PolicyID, ClaimDate, ClaimType
  - ReportedDamage, NumParties, Description

OPTIONAL (Can Leave Blank):
  - HolderAge, VehicleType, AnnualMileage, LocationUrban
  - CreditScore, PolicyStart, PolicyEnd
  - System auto-fills if missing

OUTPUT:
  - Prediction: "Simple" | "Moderate" | "Complex"
  - Confidence: 0-1 (show as percentage)
  - Probabilities: Breakdown of all 3 classes

CRITICAL:
  - Description minimum 50 characters
  - Model uses NLP analysis on description
  - Quality description = better prediction

PERFORMANCE:
  - Prediction: < 100ms per claim
  - Accuracy: 96% validation
  - Confidence: ~40% average (normal, not a bug)

SAMPLE TEST CASES (Run script to see):
  1. Minor Parking Lot Damage - $500, 1 party
  2. Complex Multi-Vehicle Accident - $15,000, 4 parties
  3. Moderate Theft Claim - $8,500, missing policy info
  4. Straightforward Collision - $3,200, 2 parties
